    Добавление пользовательского языка¶

    XC_VM использует файловую систему перевода. Каждый язык представляет собой отдельный файл .ini в каталоге src/Core/Localization/lang/. Добавление нового языка не требует изменения кода — просто создайте файл, и он автоматически появится в панели администратора.

    На установленной панели вместо этого используйте диспетчер переводов: он сохраняет ваш перевод за пределами кода, и обновление не заменяет его. Приведенные ниже действия относятся к языку, который поставляется с XC_VM.

    быстрый старт¶

    1. Сгенерируйте машинно переведенную начальную точку из en.ini:
    make lang-translate LANG_TRANSLATE=xx

    Замените xx кодом языка ISO 639-1 (например, it для итальянского, pl для польского, ja для японского). Файл еще не обязательно должен существовать — он создается с каждым ключом из en.ini. Смотрите Синхронизация переводов.

    Чтобы выполнить перевод вручную, скопируйте файл на английском языке в качестве шаблона:

    cp src/Core/Localization/lang/en.ini src/Core/Localization/lang/xx.ini
    1. Откройте xx.ini и просмотрите или переведите значения (справа от =).:
    [Language]
a_to_z = "A to Z"          ; ← translate this
access_code = "Access Code" ; ← translate this
actions = "Actions"         ; ← translate this
    1. Перейдите к Настройки → Интерфейс → Язык интерфейса и выберите новый код языка.

    Вот и все. Перезагрузка не требуется.

    Формат файла¶

    Каждый файл .ini имеет следующую структуру:

    [Language]
key = "Translated text"
another_key = "Another translated text"

    Rules:

    • Заголовок раздела [Language] равен требуемый в первой строке.
    • Ключами являются идентификаторы snake_case — не меняйте их.
    • Значения должны быть заключены в двойные кавычки; буквальная кавычка внутри значения записывается как \".
    • Сохраняйте заполнители, такие как {bin}, {count} и %s, и любые HTML-теги точно такими, как они указаны в en.ini.
    • Ключи следуют за разделами порядка и ; комментариев в en.ini.
    • Кодировка файла должна быть UTF-8 (без спецификации).

    как это работает¶

    Шаг Что происходит
    Панель загрузки Translator::init() сканирует src/Core/Localization/lang/ (в комплекте) и config/lang/ (пользовательские) на наличие *.ini файлов
    Список языков Translator::available() возвращает все найденные языковые коды из обоих каталогов
    Загрузка языка Сначала считывается связанный файл, а затем пользовательский файл; ключ, которого нет ни у одного из них, возвращается к en.ini
    Выбор пользователя Язык сохраняется в файле cookie lang (для каждого браузера) и в столбце базы данных settings.language (по умолчанию).
    Отсутствующий ключ Если ключ перевода используется в коде, но отсутствует в языке, отображается английское значение из en.ini (или название ключа, если оно также отсутствует в en.ini). Ни один языковой файл не записывается во время выполнения: менеджер переводов перечисляет, чего не хватает языку (Отсутствует только)

    Менеджер по переводам¶

    Переводы, в меню профиля рядом с Общие настройки, позволяет управлять языками панели без изменения кода. Для этого требуется разрешение settings, как и на странице настроек.

    Действие Что он делает
    Download Любой язык в виде файла .ini в порядке en.ini. Ключ, который не переводится на этот язык, содержит текст на английском языке. en.ini - это шаблон для перевода
    Upload Файл .ini для нового или существующего кода языка (tr, fil, pt-BR). Введенный вами код указывает язык; имя загруженного файла не используется
    Edit Таблица ключей / английского языка / перевода с поиском и фильтром Отсутствует только. сохранить изменения сохраняет измененные строки
    Translated Сколько ключей из en.ini переводится на данный язык

    Где хранятся пользовательские переводы¶

    Загруженные и отредактированные файлы хранятся в /home/xc_vm/config/lang/<code>.ini. Файлы, входящие в пакет Core/Localization/lang/, никогда не изменяются:

    • config/ is kept by an update, so custom translations survive updates. The bundled files are replaced by every update.
    • Пользовательский файл содержит только то, что отличается от входящего в комплект файла соответствующего языка. Это чтение над из входящего в комплект файла: оно может переопределять входящий в комплект перевод, добавлять ключ, которого нет в входящем в комплект файле, или быть языком, который панель не отправляет.
    • Значение, которое является пустым или все еще идентичным тексту на английском языке, не является переводом. Оно считается пропущенным, как и для make lang-translate. Удаление строки в редакторе или повторный ввод текста на английском языке приводит к удалению пользовательского перевода этого ключа.
    • В пакете восстановления содержится config/lang/. Резервная копия базы данных не содержит.

    Что проверяется и дезинфицируется¶

    Просмотры печатают перевод в формате HTML, поэтому загруженное или отредактированное значение проверяется перед сохранением:

    Проверять Правило
    Языковой код Две или три строчные буквы, необязательно - и область из двух-четырех букв. Это единственный источник имени файла
    Файл Размером не более 1 МБ и доступен для чтения в виде файла .ini. В случае отклонения файла указывается первая строка, которую невозможно прочитать
    Ключи Сохраняются только те ключи, которые существуют в en.ini
    HTML <b>, <i>, <strong>, <em>, <code> и <br> сохраняются без атрибутов. Любой другой тег и любой тег с атрибутом сохраняются в виде текста (&lt;a href=…&gt;)
    Другие персонажи & и " сохраняются как объекты; объект, который уже существует (&amp;, &nbsp;), остается. Обратная косая черта сохраняется как &#92;, а апостроф ' - как типографский знак ’.
    Заполнители {name} и %s сохраняются в том виде, в каком они есть
    Линии Значение равно одной строке: разрыв строки становится пробелом
    • Входящие в комплект файлы представляют собой текст самой панели и не обрабатываются. Значение, загруженное без изменений из загруженного языкового пакета, остается включенным в пакет.
    • Ссылка или значок (<a href=…>, <i class=…>) не могут быть частью пользовательского перевода. В нескольких англоязычных текстах, содержащих ссылку, они сохраняются только при использовании их полного перевода.
    • Файл, помещенный в поле config/lang/ вручную, считывается таким, какой он есть. Чтобы проверить его, воспользуйтесь функцией загрузки.

    Синхронизация переводов¶

    en.ini является источником истины. Разработчики добавляют новые строки пользовательского интерфейса в en.ini только; другие языки обновляются с учетом:

    make lang-translate                      # every <lang>.ini except en
make lang-translate LANG_TRANSLATE=ru    # a single language

    При этом выполняется tools/i18n/translate.py --ini, который перестраивает каждый языковой файл в порядке en.ini:

    Случай Результат
    Ключ уже переведен Сохранено как есть
    Ключ отсутствует в файле Машинный перевод с en.ini
    Значение по-прежнему идентично тексту на английском языке Машинный перевод
    Ключа больше нет в en.ini Удаленный (указан в выходных данных)
    • Заполнители ({bin}, %s), HTML-теги, сущности (&mdash;) и экранированные кавычки никогда не отправляются в механизм перевода, поэтому они возвращаются без изменений.
    • Движок выбирается с помощью DOCS_TRANSLATE_PROVIDER, так же, как и для документов: translators (по умолчанию, бесплатные веб-движки, без ключа API), anthropic (требуется ANTHROPIC_API_KEY) или noop (копирует английский; быстрый способ добавить недостающие ключи и удалить устаревшие без перевод).
    • Переводы кэшируются в build/docs-cache/ini-<lang>.json: при повторном запуске не выполняются сетевые вызовы, а прерванный запуск (Ctrl+C) возобновляется с того места, где он был остановлен. Если движок не справляется с поиском ключа, значение на английском сохраняется и повторяется при следующем запуске.
    • Машинный перевод - это отправная точка. Перед выполнением перевода просмотрите языковые файлы git diff и исправьте формулировки, отредактировав переведенное значение — значение, отличное от английского, никогда не будет перезаписано.

    Чаевые¶

    • Всегда используйте en.ini в качестве источника истины — содержит все ключи. В других файлах могут отсутствовать ключи; во время выполнения в них отображается текст на английском языке.
    • Отсутствующие ключи: для языка, в котором отсутствует ключ, отображается текст на английском языке. В более старых версиях такой ключ добавлялся к языковому файлу во время выполнения; сейчас ничего не записывается. make lang-translate переводит ключи, отсутствующие в прилагаемом файле.
    • Проверьте свой файл — убедитесь, что parse_ini_file() может это прочитать:
    php -r "var_dump(parse_ini_file('src/Core/Localization/lang/xx.ini', false, INI_SCANNER_RAW));" | head -20

    Дополнительные переводы¶

    Внести свой вклад в перевод проекта:

    1. Разветвите репозиторий.
    2. Создайте свой языковой файл, как описано выше.
    3. Отправьте запрос на извлечение с новым файлом .ini.

    Пожалуйста, убедитесь, что все ключи из en.ini присутствуют и переведены.
