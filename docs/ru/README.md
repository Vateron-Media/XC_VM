# <a id="xc_vm-iptv-panel"></a>Панель IPTV XC_VM

![Vateron Media Logo](https://avatars.githubusercontent.com/u/149707645?s=400&v=4)

Современная IPTV-панель с открытым исходным кодом, вдохновленная кодами Xtream. Легкая, быстрая и ориентированная на сообщество.

---

## <a id="what-is-it"></a>что это такое?

**XC_VM** - это современная IPTV-панель, построенная на PHP, Nginx, FFmpeg и MariaDB.

XC_VM поможет вам развернуть полноценную инфраструктуру IPTV:

- Управление телевизионными трансляциями, фильмами и сериалами в прямом эфире
- Управление торговыми посредниками и пользователями
- балансировка нагрузки
- Система EPG и VOD
- Инструменты мониторинга и API

💡 * Бесплатно, AGPL-3.0. Для односерверной панели не требуется ключ; балансировщики нагрузки и разветвление
демону нужен бесплатный ключ активации — смотрите раздел [Лицензирование и активация](info/licensing-and-activation.md).*

## <a id="technologies"></a>Технологии

- **Nginx** — обратный прокси-сервер и веб-сервер
- **PHP 8.3** — основная серверная часть
- **MariaDB (МариаДБ)** — база данных
- **База данных ключей** — механизм кэширования/сеанса
- **FFmpeg 8.0** — перекодирование
- **yt-dlp** — получение мультимедийных данных
- **Дено** — среда выполнения JavaScript для yt-dlp (YouTube)

XC_VM официально поддерживает Ubuntu 22.04 и протестирован 24.04.

## <a id="installation"></a>Установка

Установка на Ubuntu 22.04+:

```bash
sudo apt update && sudo apt full-upgrade -y
sudo apt install -y python3-pip unzip

latest_version=$(curl -s https://api.github.com/repos/Vateron-Media/XC_VM/releases/latest | grep '"tag_name":' | cut -d '"' -f 4)
wget "https://github.com/Vateron-Media/XC_VM/releases/download/${latest_version}/XC_VM.zip"

unzip XC_VM.zip
sudo python3 install
```
