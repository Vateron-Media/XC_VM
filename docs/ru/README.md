# XC_VM Панель IPTV

![Vateron Media Logo](https://avatars.githubusercontent.com/u/149707645?s=400&v=4)

Современная IPTV-панель с открытым исходным кодом, вдохновленная Xtream Codes. Легкая, быстрая и ориентированная на сообщество.

---

## что это такое?

**XC_VM** - это современная IPTV-панель, построенная на PHP, Nginx, FFmpeg и MariaDB.

XC_VM помогает вам развернуть полноценную инфраструктуру IPTV:

- Управление телевизионными трансляциями, фильмами и сериалами в прямом эфире
- Управление торговыми посредниками и пользователями
- балансировка нагрузки
- система EPG и VOD
- Инструменты мониторинга и API

💡 * Абсолютно бесплатно. Никаких лицензий. Никаких блокировок сервера.*

---

## Технологии

- **Nginx** — обратный прокси-сервер и веб-сервер
- **PHP 8.1** — основная серверная часть
- **MariaDB** — база данных
- **KeyDB** — механизм кэширования/сеанса
- **FFmpeg 8.0** — перекодирование
- **yt-dlp** — получение мультимедийных данных

XC_VM официально поддерживается Ubuntu с 22.04 и протестирован 24.04.

## Установка

Установка на Ubuntu 22.04+:

```bash
sudo apt update && sudo apt full-upgrade -y
sudo apt install -y python3-pip unzip

latest_version=$(curl -s https://api.github.com/repos/Vateron-Media/XC_VM/releases/latest | grep '"tag_name":' | cut -d '"' -f 4)
wget "https://github.com/Vateron-Media/XC_VM/releases/download/${latest_version}/XC_VM.zip"

unzip XC_VM.zip
sudo python3 install
```
