# <a id="adding-your-own-ffmpeg-build"></a>Добавление Вашей собственной сборки FFmpeg

Панель отправляет свои собственные сборки FFmpeg и поддерживает их в актуальном состоянии. Вы также можете добавить
создайте свою собственную версию, например, с дополнительными кодеками или аппаратным кодером,
и выбирайте его для своих стримов, как и любой другой.

---

## <a id="how-the-panel-finds-ffmpeg-builds"></a>Как панель находит сборки FFmpeg

Каждая сборка представляет собой папку в `/home/xc_vm/bin/ffmpeg_bin/`, которая содержит `ffmpeg` и
`ffprobe` двоичный файл. На панели отображается список всех таких папок, название которых имеет правильную форму, и
имя папки - это то, что хранится в настройках.

|Папка|Что это такое|
|---|---|
|`4.4`, `7.1`, `8.1`|Собственные сборки панели. Панель загружает и обновляет их каждый день.|
| `4.0` |Сборка XUI на панелях перенесена из XUI или более старой сборки XC_VM. Ничего не менялось.|
| **Your build** |Любое другое название формы, указанной ниже. Панель никогда не изменяет и не удаляет ее.|

Панель показывает каждую сборку по версии ее двоичных отчетов `ffmpeg`, а не по ее
имя папки. Папка `6.1-my`, содержащая FFmpeg пункт 6.1.2, отображается как **версия 6.1.2**.

---

## <a id="naming-your-folder"></a>Присвоение имени вашей папке

Используйте `<major>.<minor>-<name>`, например `6.1-my` или `7.1-nv`:

- `<major>.<minor>` - это версия вашей сборки FFmpeg (`6.1`, `7.1`, ...).
- `<name>` - это любое ваше собственное короткое имя: только строчные буквы и цифры.
- Полное имя может быть **не более 8 символов**, потому что именно столько
установка хранилищ.

Не используйте имя, которое использует сама панель: `4.4`, `7.1` и `8.1` заменяются на каждом
обновите, и `4.0` может содержать сборку XUI.

Папки с любыми другими именами, такими как `my-ffmpeg` или `6.1.backup`, в списке отсутствуют.

---

## <a id="adding-the-build"></a>Добавление сборки

Сборка должна выполняться в собственной системе сервера, поэтому **статическая сборка** является самым безопасным
выбор. Установите его на **каждый сервер, который запускает потоки**: главный сервер и при каждой загрузке
балансировщик. Сервер, на котором отсутствует сборка, использует вместо нее другой (см. ниже).

Запустите их на каждом сервере от имени пользователя root, указав имя своей папки и путь к двоичным файлам:

```bash
mkdir /home/xc_vm/bin/ffmpeg_bin/6.1-my
cp /path/to/ffmpeg /path/to/ffprobe /home/xc_vm/bin/ffmpeg_bin/6.1-my/
chown -R xc_vm:xc_vm /home/xc_vm/bin/ffmpeg_bin/6.1-my
chmod 755 /home/xc_vm/bin/ffmpeg_bin/6.1-my/ffmpeg /home/xc_vm/bin/ffmpeg_bin/6.1-my/ffprobe
```

Убедитесь, что он запущен на этом сервере от имени пользователя панели:

```bash
sudo -u xc_vm /home/xc_vm/bin/ffmpeg_bin/6.1-my/ffmpeg -hide_banner -version
```

Он должен вывести версию. Если он сообщает об отсутствующей библиотеке или `GLIBC_… not found`, то
сборка не подходит для этого сервера; вместо этого используйте статическую сборку.

---

## <a id="choosing-the-build"></a>Выбор сборки

1. Откройте **Настройки → Информация**. Ваша сборка появится в таблице **FFmpeg** с ее
версия и возможность ее кодирования на графическом процессоре.
2. На **Настройки → Потоковая передача**, выберите его в **Версия FFMPEG (процессор)** и в
**Версия FFMPEG (графический процессор)** если это должно выполнять работу графического процессора.
3. Сохранить. Новая сборка используется при следующем запуске каждого потока, поэтому перезапустите
потоки, которые вы хотите переместить в него прямо сейчас.

---

## <a id="when-a-server-does-not-have-the-build"></a>Когда на сервере нет сборки

Если выбранная вами сборка отсутствует на сервере, этот сервер выбирает ее сам:

1. Сборка той же версии, например `6.1` или другой `6.1-…`.
2. В противном случае используется самая новая сборка с той же основной версией, например `6.0`.
3. В противном случае используется самая новая сборка на сервере.

Таким образом, поток никогда не завершается сбоем из-за того, что в одной load balancer отсутствует ваша сборка, но он может выполняться
с другим значением FFmpeg. Установите сборку на каждом сервере, чтобы получить одинаковый результат
везде.

---

## <a id="removing-the-build"></a>Удаление сборки

Сначала выберите другую сборку в **Настройки → Потоковая передача**, сохраните, а затем удалите папку на
каждый сервер:

```bash
rm -rf /home/xc_vm/bin/ffmpeg_bin/6.1-my
```

Потоки, которые все еще работают на нем, продолжают работать до тех пор, пока не перезапустятся.
