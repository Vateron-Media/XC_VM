# Обновление сервера

Пошаговая инструкция по обновлению сервера XC_VM. Как процесс устроен изнутри — см. [Механизм обновления](ru-ru/administration/update-system.md).

> 💾 Перед обновлением рекомендуется сделать [резервную копию](ru-ru/administration/backup-strategy.md).

## Обновление через панель

**Шаг 1.** В верхнем меню панели откройте раздел **Servers**.

![Меню Servers](../../_media/update1.png)

**Шаг 2.** В выпадающем меню выберите пункт **Manage Servers**.

![Пункт Manage Servers](../../_media/update2.png)

**Шаг 3.** В таблице серверов найдите нужный сервер и нажмите кнопку меню в колонке **Actions**.

![Кнопка Actions](../../_media/update3.png)

**Шаг 4.** В открывшемся меню выберите **Server Tools**.

![Пункт Server Tools](../../_media/update4.png)

**Шаг 5.** В окне **Server Tools** нажмите кнопку **Update Server**.

![Кнопка Update Server](../../_media/update5.png)

После нажатия в базе данных создаётся сигнал `update`. В течение минуты его подхватит CRON, и обновление пройдёт автоматически: панель будет остановлена, обновлена и перезапущена. Прогресс можно контролировать по версии сервера в таблице **Manage Servers**.

## Обновление вручную (CLI)

```bash
sudo -u xc_vm /home/xc_vm/console.php update update
```

Скачивает и применяет последнее обновление с GitHub. Обычно запускается автоматически через веб-панель.
