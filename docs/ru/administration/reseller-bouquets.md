# <a id="reseller-bouquets-and-customer-order"></a>Букеты от реселлеров и заказы клиентов

Администраторы устанавливают для каждого реселлера надбавку bouquet; реселлеры выбирают и сортируют букеты
на каждого клиента. За составление букета и общий порядок заказа отвечает администратор.

## <a id="set-the-allowance"></a>Установите размер пособия

В поле **Пользователи → Редактировать реселлера → Доступ к реселлеру bouquet** выберите **Только выбранный
букеты**, выберите разрешенные букеты и сохраните. Например, разрешите реселлеру 3
букеты по 5-10 штук и 4 букета от посредника по 10-15 штук.

**Все букеты в упаковке** удаляет дополнительное ограничение. Выбрано только пустое **
букеты** из списка не разрешены. Новые ограничения распространяются на новых клиентов или на следующий
сохранение клиентов; существующие клиенты не меняются сразу.

Группе реселлеров требуется **Разрешите менять букеты** для выбора или изменения порядка.
**Создать линию** и **Сгенерировать пробную версию** по умолчанию используются букеты из пакета в пределах
надбавка этого торгового посредника: пакет 1-10 с надбавкой 5-10 по умолчанию равен 5-10.
Букеты, не входящие в комплект поставки, не могут быть добавлены. Без разрешения эти параметры по умолчанию
применять. При редактировании клиента другого реселлера применяются ограничения обоих реселлеров.

## <a id="select-and-reorder"></a>Выберите и измените порядок

1. Создайте линию/пробную версию или отредактируйте клиента. Для редактирования только букета сохраните
пакету присвоено значение **Никаких изменений**.
2. Откройте **Букеты**, выберите букеты клиента и переместите их с помощью **↑/↓**.
3. Сохраните и обновите список воспроизведения или повторно подключите проигрыватель.

Заказ каждого клиента является отдельным. Потоки сохраняют свой заказ в течение bouquet;
дубликаты отображаются при их первом появлении. Сохраненная пустая выборка остается
пустой. Изменения в шаблоне категории сохраняют заказ клиента bouquet. Игроки
при использовании их собственной сортировки может отображаться другой порядок. Изменение упаковки
по-прежнему соблюдает обычные правила покупки и кредитования.

## <a id="deploy"></a>Развертывать

Установите соответствующее ядро и запустите `php console.php db:migrate` в MAIN из
каталог приложений. Перенос `094_add_reseller_bouquet_permissions` добавляет
припуск; `096_add_customer_bouquet_order` сохраняет флаг заказа независимо
из шаблонов категорий и переносит устаревшие маркеры. Если одновременное редактирование или устаревший
если форма отклонена, перезагрузите и примените изменения еще раз. Для этой функции не требуется прокси-сервер
модуль.
