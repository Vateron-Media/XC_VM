# <a id="connection-filters-and-live-tools"></a>Фильтры подключений и интерактивные инструменты

## <a id="lines-per-ip"></a>Линий на IP-адрес

Выберите диапазон в **Линий на IP-адрес**, затем **Просмотр журналов** для клиента. Деятельность
журналы открываются с фильтрацией по этому клиенту и диапазону; **Все время** даты остаются пустыми.
Измените или снимите фильтры, чтобы расширить результаты. В ссылках на диапазон используются даты ISO и старые
закладки по-прежнему поддерживаются.

## <a id="live-stream-restart-tools"></a>Инструменты для перезапуска прямой трансляции

В поле **Быстрые инструменты → Потоки** подтвердите действие для перезапуска:

- Потоки с известным прогрессом **ниже 0,8 раза или выше 5 раз**. Точные границы
и пропущенный/неверный прогресс не совпадают.
- Отсутствуют потоки **аудио- или видеокодек**. Используйте это для каналов
ожидается, что он будет содержать оба трека.

Совпадают только запущенные живые экземпляры, включая кодеры, управляемые демонами.
Прямые источники, автономные экземпляры, VOD, радио и анализируемые экземпляры - это
исключенный. Исправные копии на других серверах продолжают работать.

В уведомлении отображаются отправленные/совпадающие запросы на перезапуск; `0/0` означает, что их нет
соответствие. После этого проверьте **Управление потоками**, чтобы подтвердить, что они вернулись онлайн.

## <a id="mag-details"></a>Детали MAG

В списках администраторов и реселлеров **Последний активный** отображает IP и провайдера из одного последнего
активное подключение. Завершенные подключения исключаются, поле "отсутствующий провайдер" остается пустым,
а доступ реселлеров остается ограниченным для их клиентов. MySQL и Redis являются
поддерживаемый.
