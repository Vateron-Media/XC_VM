# <a id="diagnostics-service"></a>Служба диагностики

`DiagnosticsService` предоставляет помощников по оперативной диагностике:

- Проверка SSL-сертификата
- проверка совместимости кодеков
- экспорт/отправка журнала панели управления
- обнаружение IP-адреса внешнего API

---

## <a id="methods"></a>Методы

### `getCertificateInfo(?string $certificate = null): ?array`

Возвращает сведения о сертификате (`serial`, `expiration`, `subject`, `path`).

Если `$certificate` равно null, путь к сертификату автоматически определяется из конфигурации SSL nginx.
Возвращает `null`, если файл отсутствует или не удалось выполнить синтаксический анализ OpenSSL.

---

### `checkCompatibility(array|string $data, bool $allowHEVC = false): bool`

Проверяет, совместимы ли медиакодеки с ограничениями проигрывателя.
Принимает полезную нагрузку FFProbe в виде массива или строки JSON.

Принятые по умолчанию кодеки включают:

- видео: `h264`, `vp8`, `vp9`, `ogg`, `av1`
- аудио: `aac`, `libfdk_aac`, `opus`, `vorbis`, `pcm_s16le`, `mp2`, `mp3`, `flac`

При `$allowHEVC=true` допускаются `hevc`/`h265` и `ac3`.

---

### `downloadPanelLogs(object $db): array`

Извлекает до 1000 последних строк из `panel_logs` (исключая `epg`), обрабатывает поля вывода и очищает строки журнала после экспорта.

Возвращаемая форма:

```php
[
  'errors' => [...],
  'version' => '...'
]
```

Выдает ошибку `Exception` при сбое запроса к базе данных.

---

### `submitPanelLogs(object $db): string|false`

По умолчанию включено. Пока параметр **Отправлять очищенные ошибки панели в службу диагностики XC_VM** включён в Настройки → Журналы, MAIN отправляет HTTPS POST на `https://www.xcvm.tech/api/v1/report`.

Запрос содержит текущую версию панели и до 1000 ошибок. Для каждой ошибки передаются только `type`, очищенные `log_message` и `log_extra`, `line`, UTC `date` и версия панели `version`, записанная с ошибкой. Пароли, токены, значения Authorization и учётные данные в URL удаляются до локального сохранения и повторно перед отправкой.

Срок хранения на стороне получателя панелью не определён. Выключение параметра прекращает будущие отправки, но не удаляет уже переданные данные. При отключённом параметре метод возвращает `false`, не читая журналы.

---

## <a id="panel_logs-shape-used-fields"></a>`panel_logs` Форма (используемые поля)

|Колонка|Тип|Значение|
| --- | --- | --- |
| `type` |строка|тип события|
| `log_message` |строка|основное сообщение|
| `log_extra` |строка|очищенный дополнительный контекст или стек вызовов|
| `line` |инт|исходная строка|
| `date` |инт|Временная метка UNIX|

---

### `getPIDs(int $rServerID): array`

Анализирует информацию о системном процессе из ответа API сервера. Возвращает структурированные данные процесса для мониторинга.

---

### `getNVENCProcesses(int $rServerID): array`

Извлекает данные процесса GPU (NVENC) из информации о графическом процессоре сервера. Используется для диагностики кодирования на графическом процессоре.
